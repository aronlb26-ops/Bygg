# A.R.E Rekond – hemsida

Statisk sajt byggd med [Astro](https://astro.build). *(Under uppbyggnad – fullständig README kommer när alla sidor är klara.)*

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # bygger till dist/
```

- Företagsuppgifter: `src/data/foretag.yaml`
- Paket, tillval och priser: `src/data/tjanster.yaml`
- Inställningar (domän, formulär, extern bokning): se `.env.example`
